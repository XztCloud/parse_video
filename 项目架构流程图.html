0️⃣ 系统启动流程三个独立进程

三个进程共享 PostgreSQL 与 Redis：
• backend/ 执行 start-api → FastAPI（入口 app.main:main，uvicorn 监听 :8000）
• backend/ 执行 start-worker → Celery Worker（入口 app.celery_app:start_celery_worker）
• frontend/ 执行 npm run dev → Next.js（:3000，通过 /api/* 代理到后端）

2️⃣ 视频复刻流程 clone_video_task + LangGraph 7 阶段
